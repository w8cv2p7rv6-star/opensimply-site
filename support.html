OpenSimply Support

← OpenSimply

Support for the founding release covers download/access problems, installation problems, packaged self-check failures, and questions about whether a GitHub project is supported.

Before requesting support, use Data & privacy → Run system check inside OpenSimply. Do not send passwords, API keys, payment card numbers, private keys, recovery codes, or other secrets in a support request.

The public support contact will be added before paid checkout is enabled.
