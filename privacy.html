OpenSimply Privacy

← OpenSimply

Desktop application. The current OpenSimply build does not require an OpenSimply account and does not send product telemetry. Saved shortcuts and managed application files are stored locally on the user's computer. GitHub searches, repository names, and repository file requests are sent directly to GitHub when the user asks OpenSimply to inspect a project.

Launch website. This site is hosted by Vercel and may receive standard web request information such as IP address, browser/user agent, requested URL, timestamps, and diagnostic/security logs as part of normal hosting.

Purchases. When paid access launches, checkout will be handled by a third-party payment/storefront provider. That provider will process the payment and account information required to complete the transaction under its own privacy terms. OpenSimply will not ask customers to send card numbers by email or chat.

Support. Information voluntarily supplied in a support request will be used to respond to that request and maintain product/support records.
